# 076 — 登录抽屉排版塌陷修复与几何规范收敛

- **日期**：2026-10-24
- **类型**：前端 UI/UX 缺陷修复与规范对齐
- **关联文件**：`src/components/NavAuthBadges.tsx`
- **关联需求**：用户反馈顶部导航登录抽屉（NavAuthBadges）排版塌陷、未连接双标签冗余、未鉴权状态交互矛盾与圆角几何不合规问题。

---

## 1. 缺陷分析与根因

1. **"编辑资料" 按钮横向受压纵向坍塌**：
   - **现象**：右侧蓝色按钮由于父级 Flexbox 空间有限且缺少 `shrink-0` 与 `whitespace-nowrap`，被挤压成细长垂直色块，汉字折行为单字竖排（`编 \n 辑 \n 资 \n 料`）。
   - **根因**：缺少抗挤压属性 `shrink-0` 及防折行属性 `whitespace-nowrap`；左侧身份区域也缺少 `min-w-0` 导致无序撑开。
2. **"Monad 链上钱包" 标题断裂**：
   - **现象**：标题被截断折行，出现 "Monad 链上" 与下一行孤字 "包"。
   - **根因**：标题标签缺少 `whitespace-nowrap` 和 `shrink-0`，右侧并排的状态徽章占满横向空间导致折行。
3. **未连接状态双重徽章冗余**：
   - **现象**：未连接钱包时，KOL 和 MON 两个余额 span 均回退为 `t("auth.wallet_unconnected")`，呈现两个并排的 `[未连接]`。
   - **根因**：未对 `walletAddress` 统一做整体条件分支判断。
4. **未登录状态下引导矛盾**：
   - **现象**：未登录用户在抽屉顶部看到的是虚拟身份占位与突出的 "编辑资料" 按钮，而不是直观的登录引导。
   - **根因**：未依据 `identity` 区分主按钮行为，未登录状态未提供直接的 `auth.to_login` 入口。
5. **圆角几何违反 AGENTS.md 第 7 条规范**：
   - **现象**：多处使用禁用的 `rounded-full` 胶囊（药丸）以及 `rounded-2xl`，违反设计体系的现代微圆角约束。

---

## 2. 修改内容

- **`src/components/NavAuthBadges.tsx`**：
  - 导入 `LogIn` 图标（`lucide-react`）。
  - 顶部导航账户胶囊按钮：`rounded-2xl` 收敛为现代矩形 `rounded-md`。
  - 用户头部卡片（Card 1）：
    - 容器转为 `rounded-lg`，内部布局添加 `gap-2`。
    - 左侧信息区域加上 `min-w-0 flex-1`，确保文字在有限空间下优雅 truncate。
    - 右侧操作按钮区分鉴权态：
      - 已登录（`identity` 存在）：展示 `[编辑资料]` 按钮（附带 `shrink-0 whitespace-nowrap rounded-md`）。
      - 未登录（`identity` 为空）：展示 `[去登录]` 按钮（调用 `handleGoogleLogin()`，附带 `shrink-0 whitespace-nowrap rounded-md`）。
  - 钱包卡片（Card 2）：
    - 容器转为 `rounded-lg`。
    - 标题增加 `shrink-0 whitespace-nowrap`，与右侧状态徽章之间增加 `gap-2`，杜绝孤字换行。
    - 优化状态徽章：未连接钱包时只渲染单个 `[未连接]` 标签；连接后才展示 KOL 与 MON 双余额。
    - 内部按钮（转账 KOL/MON、断开连接、连接钱包）：圆角全部由 `rounded-lg`/`rounded-xl` 收敛为 `rounded-md`。
  - 多轨背书卡片（Card 3）：
    - 容器转为 `rounded-lg`。
    - 各认证轨（Google、GitHub、Steam）的操作按钮全部统一增加 `shrink-0 whitespace-nowrap rounded-md`，防止任何视口下发生文本挤压折行。
