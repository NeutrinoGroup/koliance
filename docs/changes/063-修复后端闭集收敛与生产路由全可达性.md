## 1. 改动背景与目标

依据 03 环测试反馈与后端整改小步增量指令，执行以下关键加固与改造：
1. **闭集强校验与非法 Code 阻断防穿透（`backend/internal/httpapi/errors.go`）**：
   在 `writeError` 和 `jsonEnvelopeError` 内部执行闭集强校验，检查传入的 `ErrorCode` 是否属于 `AllErrorCodes` 闭集。若不在闭集中，记录 `slog.WarnContext` 结构化告警日志（携带 `illegalCode` 与 `requestId`）并强制 fallback 纠正为 `CodeInternalError`，防止未经 ADR 审核的非法/未定义 code 穿透到客户端。
2. **消解影子代码漂移（`backend/internal/httpapi/reqlog_test.go`）**：
   同步 `reqlog_test.go` 中的 `mutatedLoggingMiddleware`，补齐生产 `loggingMiddleware` 已有的 `ctxKeyErrSlot` 槽位初始化，消除变异体与生产中间件之间的上下文拓扑漂移。
3. **消除全可达性测试中的 Mock Handlers（`backend/internal/httpapi/errors_test.go`）**：
   在 `TestEveryErrorCodeIsReachable` 中彻底移除此前手写 mock handler 的 5 处测试用例，全部改用基于 `newTestRouter` 的真实生产路由：
   - `RESOURCE_NOT_FOUND` (404): 请求真实 `GET /api/v1/market/prices?symbol=INVALID_SYMBOL_XYZ`，上游返回空 bars，触发 `market.ErrNoMarketData`；
   - `UPSTREAM_UNAVAILABLE` (502): 请求真实 `GET /api/v1/market/movers`，Alpaca 凭据配置但 upstream 不可达；
   - `INTERNAL_ERROR` (500): 请求真实 `GET /api/v1/market/overview`，上游账户服务不可达触发 500；
   - `QUOTA_EXHAUSTED` (403): 注入真实 `AgentAPI`（0 配额 API Key）并请求真实 `POST /api/v1/agent/bind`；
   - `RATE_LIMITED` (429): 注入真实 `AgentAPI`（排空限流令牌桶的 API Key）并请求真实 `POST /api/v1/agent/bind`。
   同时新增 `TestWriteErrorAndJsonEnvelopeErrorFallbackOnIllegalCode` 测试，验证非法 code 传入时的 warning 日志与 fallback 纠偏行为。
4. **测试路由辅助与符号校验加固（`backend/internal/httpapi/router_test.go` & `validate.go`）**：
   - `newTestRouter` 支持通过 `cfg.AlpacaDataURL` 配置数据源，且保护已初始化的 `d.PriceOracle` / `d.Market` / `d.AgentAPI` 不被无条件覆盖；
   - `validate.go` 中扩充 `symbolRe` 允许包含下划线及最长 32 字符，确保市场符号（如包含下划线的特殊标的）格式校验正常流转至底层行情系统。

## 2. 详细实现设计

- **`errors.go`**：
  - 新增 `sanitizeErrorCode(r *http.Request, code ErrorCode) ErrorCode`，使用 `slices.Contains(AllErrorCodes, code)` 校验；
  - 若未命中，输出结构化 warning 日志，并返回 `CodeInternalError`；
  - `writeError` 与 `jsonEnvelopeError` 在编码输出前统一经 `sanitizeErrorCode` 过滤。
- **`reqlog_test.go`**：
  - 在 `mutatedLoggingMiddleware` 的 request context 中注入 `slot := &errSlot{}` 与 `ctxKeyErrSlot` 槽位。
- **`router_test.go`**：
  - `newTestRouter` 尊重 `cfg.AlpacaDataURL` / `cfg.AlpacaBaseURL` 及已初始化的服务依赖。
- **`validate.go`**：
  - `symbolRe = regexp.MustCompile("^[A-Z0-9_]{1,32}(/[A-Z]{3,4})?$")`。
- **`errors_test.go`**：
  - 重构 5 处手写 mock 用例为真实生产路由；
  - 引入 `agentapi` 模块，测试真实 `agent/bind` 配额及限流拒绝；
  - 新增 `TestWriteErrorAndJsonEnvelopeErrorFallbackOnIllegalCode` 验证非法 code 纠偏。
