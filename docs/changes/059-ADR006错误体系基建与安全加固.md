# 059 - ADR-006 错误体系基建、判据消解与安全泄漏点加固（Step 2.1）

- **状态**：已完成
- **日期**：2026-10-13 (UTC)
- **关联**：`docs/adr/ADR-006-统一报错处理体系.md` · `docs/changes/058-ADR006成对互审与词表定稿.md` · issue #33
- **作者/执行**：backend-dev (Go / 后端工程专家)

---

## 1. 改动背景与目标

依据 ADR-006 与 058 定稿，完成 02 开发环 Step 2.1 的基础设施铺设：
1. **消解既有判据冲突（C1~C3）**：更新 `market_test.go` 与 `market_edge_qa_test.go` 中的拒绝体/无数据键断言，从单一 `["error"]` 升级为闭集 `["code", "error", "requestId"]`，增补负向对照。
2. **`reqlog.go` 增强脱敏与槽位机制（SEC-P0-3）**：引入 `errSlot` 指针槽位与 `recordError` / `requestError`；增强 DSN 正则（支持引号/反引号前缀）与 Alpaca 上游响应体脱敏正则 `reTruncatedAlpacaBody`。
3. **`health.go` 安全加固（SEC-P0-1）**：探针 panic 文案固定为 `"probe panicked"`，探针错误脱敏并剥离 URL query 参数（防止 Steam API key 等凭据泄露）。
4. **新建 `errors.go` 与 `errors_test.go`**：定义 12 个强类型 `ErrorCode` 常量、闭集文案映射表 `errorCopy`、`writeError` 与 `jsonEnvelopeError`，编写闭集、槽位记录与负向单测。
5. **首个接入点验证**：在 `router.go` 的 `marketData` 闭包守卫中将旧 `jsonError` 替换为 `writeError(..., CodeServiceNotConfigured, ...)`，打通报错信封与请求级链路。

---

## 2. 详细实现记录

- `backend/internal/httpapi/errors.go` & `errors_test.go`:
  - 12 个 `ErrorCode` 强类型枚举与 `errorCopy` 闭集文案；
  - `writeError` 与 `jsonEnvelopeError`；
  - 闭集校验单测、中间件 raw error 记录单测、负向单测。
- `backend/internal/httpapi/router.go`:
  - `marketData` 闭包守卫切换为 `writeError(w, r, http.StatusServiceUnavailable, CodeServiceNotConfigured, errors.New(...))`。
- `backend/internal/httpapi/market_test.go`:
  - `assertRefusal` 键检查更新为 `["code", "error", "requestId"]`。
  - Payload 检查改为 `Code == "SERVICE_NOT_CONFIGURED"` 且不含 API 密钥等敏感信息。
  - 增补 `TestAssertRefusalNegativeControl`。
- `backend/internal/httpapi/market_edge_qa_test.go`:
  - `TestIndyNoDataMeansNoNumbers` / `TestIndyRefusalCarriesNoPriceFieldAtAll` 键检查更新为闭集 `["code", "error", "requestId"]`。
- `backend/internal/httpapi/reqlog.go` & `reqlog_test.go`:
  - `errSlot` 堆指针槽位机制；
  - `reDSN` 前缀支持反引号、单引号、双引号、括号等；
  - `reTruncatedAlpacaBody` 正则匹配与脱敏；
  - 补齐单元测试。
- `backend/internal/httpapi/health.go` & `health_test.go`:
  - panic 文案固定收敛为 `"probe panicked"`；
  - `runProbe` 出口脱敏与 URL query 剥离；
  - 补齐单元测试。
