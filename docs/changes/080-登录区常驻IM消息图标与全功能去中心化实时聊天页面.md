# 080-登录区常驻IM消息图标与全功能去中心化实时聊天页面

## 1. 变更背景与目标

针对用户提出的「在登录这里添加一个消息格式的图标；然后有个im的实时聊天页面」需求，本迭代在 GAP-83 架构基础上进行前端入口与全功能实时会话页面的扩展落地：
1. **登录区常驻消息格式图标**：在顶部导航登录按钮旁（`NavAuthBadges.tsx`）常驻展示消息格式图标，无需区分登录与访客状态，点击一键直达 `/im` 实时聊天页面；若当前处于 `/im` 路径，则呈现赛博青边框高亮与阴影辉光，并在角标配备微呼吸感脉冲提示点。
2. **专属去中心化实时聊天全屏页面 (`/im`)**：
   - 采用 Web2.5 现代科技暗色终端风格，无缝集成全局导航与页脚。
   - **左侧常用联系人抽屉与管理面板**：支持好友搜索过滤、一键展开添加 0x 地址表单（包含 42 位 EVM 地址格式校验与禁止添加本人地址防御）、联系人一键移除。
   - **右侧实时会话与交互控制台**：
     - 顶部常驻会话人头像、昵称、0x 完整地址、一键复制、Monad Testnet 区块浏览器跳转以及 `[LOCKED · 信用认证]` 徽章。
     - 实时消息流：支持文本超链接自动正则识别高亮（赛博青）、Base64 WebP 图片缩略图微览与点击全屏展开 Lightbox 灯箱、Monad 链上转账凭据卡片直达、P2P KOL 社交红包卡片及「拆开红包」多巴胺动效触发。
     - 底部集成输入框（Enter 发送）、图片本地选择与剪贴板截图粘贴（HTML5 Canvas 前端压缩为 WebP <50KB 直存 DB）、发红包抽屉、快捷转账唤起。
     - 乐观轮询机制：每 2.5 秒轻量同步会话，页面失焦（`visibilityState !== 'visible'`）时自动暂停节流，保障高吞吐下的平稳通信。
     - 未登录/访客状态自适应：呈现炫酷赛博终端欢迎卡片，配备一键「连接 Monad 钱包 / 登录」唤起按钮。
3. **门禁与合规约束严格执行**：
   - 严格遵循 `AGENTS.md` 规范：全文零 Unicode Emoji，使用 `[LOCKED · 信用认证]`、`[SUCCESS]`、`[LIVE · MONAD TESTNET]` 等文本结构指示。
   - 严格遵循几何微圆角规范：所有按钮严格采用 `rounded-md`，卡片与面板采用 `rounded-lg` 或 `rounded-xl`，严禁 `rounded-full` 椭圆气泡。
   - 配色使用深邃 Monad 紫（`#836ef9`）、赛博青（`#00f2fe`）、翡翠绿（`#10b981`）与冷石板灰，无黄色/琥珀色。

## 2. 变更内容清单

### 2.1 页面与路由
- `src/app/im/page.tsx`: 全新创建的去中心化实时 IM 通讯录与即时会话终端页面，支持双栏响应式布局（移动端自动切换联系人与会话视图）、富文本消息渲染、图片灯箱预览、P2P 红包拆包与转账联动。
- `src/components/Navbar.tsx`:
  - 在 `NavView` 联合类型中增加 `"IM"` 视图标识，支持 Navbar 自定义高亮。
  - 移除顶部导航栏中冗余的 `AGENTCARD`（Agent名片）一级路由按钮，将 3D AI Card 扫描矩阵唯一保留在首页最下方终章区域（`<AgentCardShowcase />`），避免内容重复并优化顶部导航空间。

### 2.2 导航入口与组件升级
- `src/components/NavAuthBadges.tsx`:
  - 登录按钮左侧常驻消息格式图标按钮（高度尺寸规范为 `h-9 w-9 shrink-0` 匹配顶栏），使用 `<Link href="/im">` 包装，添加 `pathname === "/im"` 激活态判断与赛博青脉冲角标。
  - 下拉账户菜单中在用户信息正下方常驻增加「实时IM消息与通讯录」一键直达入口（全用户状态可见，即使未连接钱包亦可直接进入）。
  - 下拉菜单钱包操作区保持「好友与IM消息」路由跳转。
- `src/components/TransferModal.tsx`:
  - 新增 `defaultRecipient?: string` 属性，支持从 `/im` 会话头部或快捷按钮一键拉起转账弹窗时自动预选并锁定收款人。

### 2.3 测试套件
- `tests/im-page.test.ts`:
  - 验证 `Navbar.tsx` 中 `NavView` 对 `"IM"` 的类型支持。
  - 验证 `NavAuthBadges.tsx` 中常驻 `/im` 链接、`MessageSquare` 图标、激活态及下拉菜单跳转。
  - 验证 `/im` 页面存在性、默认导出及关键能力集成（轮询、灯箱、红包、Canvas 压缩、转账凭据）。
  - 验证全局零 Emoji 指令与严格矩形微圆角几何约束（无 `rounded-full` 按钮/卡片）。
