## 1. 变更背景与目标
- 用户反馈在 `/?view=INDEX` 的核心问题问答区（`QuantumProtocolStream`），希望将字体调整为黑色提高与毛玻璃背景的对比度与可读性。
- 原背景着色器（`ChromaFlow`）仅在用户移动鼠标时触发液体搅动，静止时无明显动态。用户要求能够自动触发背景流体动效，并添加淡淡的波纹层次。

## 2. 修改文件清单
1. `src/components/QuantumProtocolStream.tsx`:
   - 核心标题（`IDENTITY`, `REPUTATION`, `EXECUTION`）由 `text-white` 改为高对比度的纯黑 `text-black font-black`。
   - 问题描述由 `text-slate-300` 调整为深炭灰 `text-slate-900 font-medium`。
   - 解决方案标签由暗色调调整为清晰的湖蓝微晶配色（`text-cyan-950 font-semibold bg-cyan-100/60 border-cyan-300/40 border-l-cyan-600`）。
   - 顶部标头、坐标串、Phase 指示灯与底部规格文本同步深色化，保持视觉层级与对比度。
2. `src/components/GlassBackground.tsx`:
   - 引入 `shaders/react` 的 `<Ripples>` 物理波纹组件，添加柔光叠加的淡淡水面波纹。
   - 叠加双层径向脉冲波纹（Radial Gradient Pulse），呈现有机起伏的淡淡涟漪光效。
   - 增加自主流体驱动循环（Autonomous Fluid Motion Driver），当用户未操作鼠标超过 400ms 时，以 Lissajous 轨道模拟柔和微动，自动激活着色器流动，并与用户真实鼠标事件无缝融合。
3. `src/components/CursorTrail.tsx`:
   - 在光标尾迹判定中增加 `e.isTrusted` 真实事件校验，防止背景着色器的自主合成事件在无光标处产生粒子杂讯。
