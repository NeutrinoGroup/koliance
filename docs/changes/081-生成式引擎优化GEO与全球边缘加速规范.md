# 081 · 生成式引擎优化（GEO）与全球边缘加速规范（GAP-84）

## 1. 变更背景与治理动机

依据生产环境现场复测结果，此前合入主干的公开定价、技术文档与合规三件套均已在生产边缘节点稳定上线（全站 HTTP 200，TLS 1.3 + HSTS，TTFB 0.83 秒）。为进一步满足对生成式 AI 搜索引擎（Generative Engine Optimization - GEO，涵盖 ChatGPT Search、Perplexity AI、Claude、Google Gemini / AI Overviews、Copilot）的最高级别支持，本项目启动专项 GEO 与全球边缘性能治理：

1. **AI 引擎直接引用率与事实锚定**：各大模型（如 Perplexity / OpenAI SearchBot）在生成答案时高度依赖直接定义、量化指标与结构化知识图谱。原站虽有基础 Schema，但缺乏完整的术语集（DefinedTermSet）、数据集（Dataset）与高频问答全集（FAQPage）。
2. **LLM 单一文件全景上下文规范（llms-full.txt）**：依据社区 Answer.AI 标准，AI Agent 倾向于通过单一机器可读 Markdown 文件一次性载入全部 API 契约、数学不变量与智能合约地址，避免高频多轮 HTTP 请求导致的截断或信息丢失。
3. **AI 抓取代理准入与全球边缘缓存**：原 `robots.ts` 抓取白名单未完全覆盖新兴检索代理（如 `OAI-SearchBot`、`Claude-Web`、`Meta-ExternalAgent` 等）；且关键机器可读文件缺少 Vercel Anycast Edge 边缘缓存指令。

---

## 2. 变更内容与架构设计

### 2.1 落地 Answer.AI 规范的 `llms.txt` 与 `llms-full.txt`
- 重构 `public/llms.txt`：严格遵循 Markdown H1 标题、引述摘要、核心路由链接与模型引用规则（Guidelines for AI Models & Citations）。
- 新建 `public/llms-full.txt`：单文件全量技术白皮书，直接包含：
  - 核心协议定位与价值主张；
  - Monad 测试网（Chain ID 10143）三个已部署权威合约地址与区块链浏览器直达链接；
  - 完整 SaaS 容量矩阵（Starter $0.00 / Growth Pro $19.90 / Enterprise Scale $149.00）与 14 天未消耗额度退款机制；
  - EIP-712 会话密钥授权标准结构与单笔/日度额度风控；
  - ADR-006 闭集状态码定义；
  - 整数精度无截断漂移数学不变量。

### 2.2 扩展 AI 检索机器人白名单（`src/app/robots.ts`）
- 显式声明并放行各大生成式引擎抓取代理：
  `GPTBot`、`ChatGPT-User`、`OAI-SearchBot`、`ClaudeBot`、`anthropic-ai`、`Claude-Web`、`PerplexityBot`、`Google-Extended`、`GoogleOther`、`Applebot-Extended`、`cohere-ai`、`Meta-ExternalAgent`、`FacebookBot`、`DuckAssistBot`、`Amazonbot`、`Bytespider`。
- 将 `/llms.txt` 与 `/llms-full.txt` 纳入公开允许抓取路径，并显式配置 `host` 与 `sitemap`。

### 2.3 扩充 Schema.org 结构化知识图谱与 SSR 深度语义层（`src/app/layout.tsx`）
- 在 `<head>` 中新增 `<link rel="alternate" type="text/plain" href="/llms-full.txt" title="Full LLM Knowledge Base" />` 声明；
- 扩展 Schema.org JSON-LD `@graph`：
  - `Organization`：注入 `contactPoint`（支持中英文多语种支持渠道）与 `knowsAbout` 知识领域；
  - `DefinedTermSet`：定义 Agent Card、EIP-712 Session Key、Monad Parallel EVM、KOL Token 核心概念；
  - `Dataset`：定义多标的实时期权行情与链上可验证数据源；
  - `FAQPage`：扩充至 7 个权威问题直接问答（涵盖定价、合约地址、并行 EVM 加速机制、会话密钥安全边界与退款安全港政策）。
- 升级 `<noscript>` 语义回退层：确保无 JS 渲染能力的轻量级 AI 爬虫在首个 HTTP 响应中即可完整解析全部标价、合约地址与产品特性。

### 2.4 全球边缘缓存（Edge Geo-Caching）与 CORS 赋能（`next.config.ts`）
- 为 `/(llms.txt|llms-full.txt|sitemap.xml|robots.txt)` 配置全球边缘缓存规则：
  - `Cache-Control: public, max-age=3600, s-maxage=86400, stale-while-revalidate=86400`；
  - `Access-Control-Allow-Origin: *` 允许任何跨域第三方 AI Agent 直接并行抓取。
