# 079-Web2.5好友通讯录与KOL双轨激励及多巴胺动效

## 1. 变更背景与目标

针对 Monad 链上转账每次繁琐手动输入 42 位 0x 地址的痛点，以及 KOL 代币在 Monad 测试网总硬顶不可随意修改增发的客观约束，本迭代按照系统架构演进规划落地以下核心能力：
1. **Web2.5 极简通讯录与常用联系人**：无需过重的 Web3 握手协议，实现常用好友通讯录存储、一键回填与锁定转账地址（防篡改）、信用徽章展示以及富文本/图文即时消息支持（Canvas 压缩 WebP Base64 直存 DB 与外链图片微缩预览，零第三方云存储依赖）。
2. **KOL 代币双轨制金库行为激励池与点对点转赠闭环**：严禁修改链上合约代码，在系统数据库记录用户行为奖励（首次绑定钱包 +100 KOL、首次开卡 +150 KOL、首次创建 API Key +50 KOL、AgentCard 消费 10% 等值 KOL 自动返现、Stripe 充值送币 1:10），支持满额（50 KOL）一键提现至链上。点对点红包转赠执行严格的发送方扣除与接收方入账，杜绝无背书虚假增发，同时防御 `NaN`/`Infinity` 算术投毒与伪造请求。
3. **原生视听数触多巴胺奖励动效**：封装 `RewardCelebrationModal`，复用 `canvas-confetti` 赛博深紫/青离子彩带 + 浏览器原生 Web Audio API 实时合成纯正大五度和弦（0 外部 MP3 网络延迟）+ 动态数字跳动递增 + 移动端微震动，支持即时聊天内「拆开红包」交互触发，遵循 AGENTS.md 现代矩形微圆角与无黄色禁令。

## 2. 变更内容清单

### 2.1 数据库结构与迁移
- `backend/migrations/006_friends_messages_rewards.sql`:
  - `friends` 表：存储用户联系人列表，带有 `(user_id, friend_wallet)` 唯一约束与索引。
  - `direct_messages` 表：支持 `TEXT`、`IMAGE`、`TRANSFER_RECEIPT`、`GIFT` 四类消息类型与 JSONB 元数据。
  - `user_rewards` 表：记录链下行为激励台账，支持 `CLAIMABLE` 与 `WITHDRAWN` 状态，建立用户行为索引以执行防女巫终身单次约束。
  - 启用 Row Level Security (RLS) 并配置严格权限划分。

### 2.2 数据访问层与防女巫逻辑 (`src/lib/`)
- `src/lib/friendsDb.ts`: 好友通讯录增删查，内存降级容灾，禁止添加本人钱包为好友。
- `src/lib/directMessagesDb.ts`: 消息拉取与发送，支持富文本、Canvas 压缩 WebP Base64 与转账凭据。
- `src/lib/rewardsDb.ts`:
  - 激励台账发放、防女巫唯一性校验（`WALLET_BIND`、`FIRST_CARD`、`FIRST_API_KEY` 终身限领 1 次且服务端强制锁死标准额度）。
  - `sendRewardGift(senderId, recipientId, amountKol)`：严格检查发送方可用余额，从已领凭据按先进先出/扣减记录对账扣除，接收方生成对应入账流水，全平台总供给严密守恒。
  - 全流程 `Number.isFinite` 校验，防御 `NaN` 和 `Infinity` 算术投毒破坏余额计算。
  - 账户余额聚合与满额 50 KOL 提现控制及合法 0x 地址格式校验。

### 2.3 API 服务路由 (`src/app/api/`)
- `/api/user/friends`: 提供 GET、POST、DELETE 接口，严格通过 Session Token 鉴权，防自添加。
- `/api/user/messages`: 消息历史查询与发送，支持 3 秒轻量轮询，禁止向自身发送消息，全量载荷大小校验（< 200KB）。
- `/api/user/rewards`:
  - 查询可提现余额与领取记录。
  - 增加 `action === "SEND_GIFT"` 处理，执行转赠与自动生成私信红包消息。
  - 增加 `action === "CLAIM_ACTION"` 防越权与防虚假增发：严禁客户端直接声明 `action_type === "GIFT"`，限制返现单笔上限 10 KOL，限制 Stripe 充值上限 1000 KOL。
- `/api/auth/wallet/route.ts`: 首次通过 EIP-191 验签时自动发放 +100 KOL 奖励。
- `/api/console/api-keys/route.ts`: 首次创建开发者 API Key 时自动发放 +50 KOL 奖励。

### 2.4 前端组件与交互升级
- `src/components/RewardCelebrationModal.tsx`:
  - 纯原生 Web Audio API 合成和弦（C5 523.25Hz, E5 659.25Hz, G5 783.99Hz, C6 1046.50Hz），零音频网络延迟。
  - `canvas-confetti` 粒子全屏喷射（Monad 紫 `#836ef9`、赛博青 `#00f2fe`、翡翠绿 `#10b981`）。
  - 数字从 0 到目标额度平滑滚屏跳动。
  - 现代矩形微圆角 `rounded-lg` / `rounded-md`，无椭圆胶囊。
- `src/components/TransferModal.tsx`:
  - 弹窗顶部常驻显示 KOL Token 实时余额与原生 MON 余额。
  - 收款人上方集成「好友快捷横滑抽屉」，点击好友一键回填 42 位 0x 地址并展示信用徽章。
  - 新增一键锁定转账地址（锁定好友头像、名称、`[LOCKED · 信用认证]` 徽章与解锁按钮），防止误改。
  - 输入新地址可一键“保存为常用好友”。
  - 转账成功后自动推送转账凭证卡片至即时聊天。
- `src/components/DirectMessageModal.tsx`:
  - 正则自动匹配超链接转换为可点击高亮链接。
  - 外部图片 URL 自动解析（`getImageUrlFromContent`）并渲染「外链微缩预览」卡片，点击可在大图浮层中查看。
  - 支持本地截图与文件通过 HTML5 Canvas 缩放到 600px 压缩为 WebP Base64（体积 < 50KB）直存 DB。
  - 支持 `TRANSFER_RECEIPT` 与 `GIFT` 专属卡片渲染。
  - `GIFT` 消息集成「拆开红包」交互按钮，接收方点击后触发 Web Audio 和弦、微触感震动与 `RewardCelebrationModal` 全屏彩带。
  - 抽屉内增加「发送红包」面板，允许用户直接从链下激励金库扣减余额赠送给好友。
- `src/components/AgentCardTerminal.tsx`:
  - 集成首次开卡 `FIRST_CARD` (+150 KOL) 领取逻辑，持久化同步至数据库激励台账。
  - 充值赠币与消费返现持久化同步调用后端，防止刷新页面后奖励丢失。
  - 全面规范化几何微圆角（`rounded-lg` 卡片/标签页、`rounded-md` 按钮/徽章、`rounded-sm` 进度条）。
- `src/components/DeveloperConsole.tsx` 与 `src/components/NavAuthBadges.tsx`:
  - 移除黄色/琥珀色高亮，统一采用 Monad 紫与赛博青。
  - 移除 `rounded-full` 违规圆角，调整为 `rounded-md` 微圆角。
