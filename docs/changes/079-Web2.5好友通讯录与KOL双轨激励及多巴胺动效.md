# 079-Web2.5好友通讯录与KOL双轨激励及多巴胺动效

## 1. 变更背景与目标

针对 Monad 链上转账每次繁琐手动输入 42 位 0x 地址的痛点，以及 KOL 代币在 Monad 测试网总硬顶不可随意修改增发的客观约束，本迭代按照系统架构演进规划落地以下核心能力：
1. **Web2.5 极简通讯录与常用联系人**：无需过重的 Web3 握手协议，实现常用好友通讯录存储、一键锁定转账地址、信用徽章展示以及富文本/图文即时消息支持（Canvas 压缩 WebP Base64 直存 DB，零第三方云存储依赖）。
2. **KOL 代币双轨制金库行为激励池**：严禁修改链上合约代码，在系统数据库记录用户行为奖励（首次绑定钱包 +100 KOL、首次开卡 +150 KOL、首次创建 API Key +50 KOL、AgentCard 消费 10% 等值 KOL 自动返现、Stripe 充值送币 1:10），支持满额（50 KOL）一键提现至链上。
3. **原生视听数触多巴胺奖励动效**：封装 `RewardCelebrationModal`，复用 `canvas-confetti` 赛博深紫/青离子彩带 + 浏览器原生 Web Audio API 实时合成纯正大五度和弦（0 外部 MP3 网络延迟）+ 动态数字跳动递增 + 移动端微震动，遵循 AGENTS.md 现代矩形微圆角与无黄色禁令。

## 2. 变更内容清单

### 2.1 数据库结构与迁移
- `backend/migrations/006_friends_messages_rewards.sql`:
  - `friends` 表：存储用户联系人列表，带有 `(user_id, friend_wallet)` 唯一约束与索引。
  - `direct_messages` 表：支持 `TEXT`、`IMAGE`、`TRANSFER_RECEIPT`、`GIFT` 四类消息类型与 JSONB 元数据。
  - `user_rewards` 表：记录链下行为激励台账，支持 `CLAIMABLE` 与 `WITHDRAWN` 状态，建立用户行为索引以执行防女巫终身单次约束。
  - 启用 Row Level Security (RLS) 并配置严格权限划分。

### 2.2 数据访问层与防女巫逻辑 (`src/lib/`)
- `src/lib/friendsDb.ts`: 好友通讯录增删查，内存降级容灾。
- `src/lib/directMessagesDb.ts`: 消息拉取与发送，支持富文本、Canvas 压缩 WebP Base64 与转账凭据。
- `src/lib/rewardsDb.ts`: 激励台账发放、防女巫唯一性校验（`WALLET_BIND`、`FIRST_CARD`、`FIRST_API_KEY` 终身限领 1 次）、账户余额聚合与满额 50 KOL 提现控制。

### 2.3 API 服务路由 (`src/app/api/`)
- `/api/user/friends`: 提供 GET、POST、DELETE 接口，严格通过 Session Token 鉴权。
- `/api/user/messages`: 消息历史查询与发送，支持 3 秒轻量轮询与图片大小校验（< 200KB）。
- `/api/user/rewards`: 奖励台账查询、行为上报与批量金库提现。
- `/api/auth/wallet/route.ts`: 首次通过 EIP-191 验签时自动发放 +100 KOL 奖励。
- `/api/console/api-keys/route.ts`: 首次创建开发者 API Key 时自动发放 +50 KOL 奖励。

### 2.4 前端组件与交互升级
- `src/components/RewardCelebrationModal.tsx`:
  - 纯原生 Web Audio API 合成和弦（C5 523.25Hz, E5 659.25Hz, G5 783.99Hz, C6 1046.50Hz），零音频网络延迟。
  - `canvas-confetti` 粒子全屏喷射（Monad 紫 `#836ef9`、赛博青 `#00f2fe`、翡翠绿 `#10b981`）。
  - 数字从 0 到目标额度平滑滚屏跳动。
  - 现代矩形微圆角 `rounded-lg` / `rounded-md`，无椭圆胶囊。
- `src/components/TransferModal.tsx`:
  - 弹窗顶部常驻显示 KOL Token 实时余额与原生 MON 余额。
  - 收款人上方集成「好友快捷横滑抽屉」，点击好友一键回填 42 位 0x 地址并展示信用徽章。
  - 输入新地址可一键“保存为常用好友”。
  - 转账成功后自动推送转账凭证卡片至即时聊天。
- `src/components/DirectMessageModal.tsx`:
  - 正则自动匹配超链接转换为可点击高亮链接。
  - 支持本地截图与文件通过 HTML5 Canvas 缩放到 600px 压缩为 WebP Base64（体积 < 50KB）直存 DB。
  - 支持 `TRANSFER_RECEIPT` 与 `GIFT` 专属卡片渲染。
- `src/components/NavAuthBadges.tsx`: 全局挂载奖励监听器，当捕获 `koliance:reward` 事件时触发多巴胺弹窗。
- `backend/internal/agentcard/service.go`: 微支付授权扣款成功时自动返还 10% 等值 KOL (`CashbackKOL`)。
