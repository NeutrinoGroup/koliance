## 1. 两处缺口（falsifier 独立发现，本节为复述；复现见 §4「改前」）

### 缺口 A-1′ —— 判据夹缝：注释宣称堵住了「文案里的数字」，代码没堵

`market_test.go:134-136` 的注释**声明**：

> a raw number would be a price with a reassuring label, and **a number embedded in the message
> text would be a price wearing a sentence**.

`assertRefusal` 实际只断言 `error` 的值是 **JSON 字符串**。**字符串里的数字它看不到** ——
而 `jsonTree` 的数字遍历只看 **JSON 数字节点**，不看字符串内容。故注释的后半句是**无判据的宣称**。

### 缺口 C-3 —— 第五个写死 `true`

`router.go:106` 的 `"agentcard": true` 是 **字面常量**。同一个 map 里其余键都有依据：

| 键 | 依据 |
| --- | --- |
| `steam` / `github` / `alpaca` / `pyth` | 真探针（`runHealthProbes`，逐次调用上游） |
| `stripe` | `cfg.StripeSecretKey != ""`（配置事实） |
| `database` | `d.DB != nil && d.DB.IsConnected`（运行时事实） |
| **`agentcard`** | **无 —— 字面 `true`** |

`029`/`030` 把四个集成键从写死 `true` 里救了出来，**却漏了第五个**。它同样是一个
「从未接触过该模块的进程产出的状态徽章」。

## 2. 修法

### A-1′ —— 选 **(a) 实现它**，不是 (b) 改注释

**理由**：这条性质**可以被可靠地窄判**，且拒绝体是**模板化文本**（只含变量名与英文单词），
不存在「合法文案里天然带数字」的误伤面。把注释降级为「该面不判」等于**放弃 issue #14 最窄的一层**
—— 「把上一笔收盘价写进 503 的括号里」正是最省事、最像运维提示的夹带方式。故实现它。

**窄断言的形式（性质，不是禁词表）**：`error` 文案中不得出现**价格形态的数字**：

```
\d+\.\d{2,}     两位以上小数的十进制数   → 999.99 / 7.1429 / 1.0013
\d{3,}          三位以上连续数字         → 150 / 999
```

**刻意不匹配**：`2/2`、一位数、两位小数以下 —— 合法运维散文会用到它们。本包全部拒绝文案
（`marketData` 的 503 文案、`ErrAlpacaCredentialsMissing`）实测**一个数字都没有**，
只含 `ALPACA_API_KEY` / `ALPACA_API_SECRET` 等**变量名**，故误伤面为空。是**形状判据**，
不是「我们想得到的那几个数」的枚举 —— 枚举抓不到没想到的那个（`030` §2 同源理由）。

### C-3 —— 给它**真实依据**，并**如实标注**

**理由**：先排除另两条路 ——

- **移出 `services`**：`agentcard` 是已发布的响应字段（`docs/changes/027` 的记录样张里就有它）。
  移除是**响应契约变更**，代价大于收益，且 `027` 是**已发生的事实**、不改写。
- **如实标注「恒 true」**：那只是把「无判据」写成中文，**缺口照旧**。任务要求「不留写死 true 且无判据」。

故取**真实依据**：`d.Cards != nil`。这不是同义反复 ——

- `agentcard` 是**本地模块**，**没有上游可探**，故它**不该**进 `probes`（进了就是假探针）；
- 它的诚实判据就是**装配事实**：`Deps.Cards` 为 nil 时，`/api/v1/agentcard/*` 的
  `d.Cards.CreateCard(...)` 会在**每个请求上空指针 panic**；
- 生产装配是无条件的（`cmd/api/main.go` 恒调 `agentcard.NewService(...)`），
  但**这里判的是运行时事实而不是假设它**：表达式**可以**为 false，故它**不是**常量。
