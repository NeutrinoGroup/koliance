# 083 — IM 图标高质感优化与系统主题渐变灰重构

## 1. 变动背景与设计目标 (Context & Objectives)

在完成 GAP-83 (好友通讯录、转账快捷填充、KOL 行为激励与多巴胺视听反馈) 与 GAP-84 (GEO 搜索引擎优化) 之后，根据设计走查与用户反馈：
1. **线上更新状态解答**：解释 `https://koliance.vercel.app` 线上暂未更新的根本原因（GitHub 仓库代码已完全合并，但 Vercel 自动部署处于 10月11日 冻结状态，需在 Vercel 控制台触发 Redeploy 或检查 Webhook 连接）；
2. **IM 消息入口高质感重塑**：顶部导航栏登录区与个人中心下拉菜单中的 IM 快捷入口，从扁平蓝黑样式重塑为 Linear/Stripe 水准的高级渐变灰质感，带微发光外框、微圆角矩形 (`rounded-md`) 与动态青色呼吸指示灯；
3. **IM 页面与系统主题渐变灰重构**：告别单调扁平的纯黑色背景 (`#0d1017`)，重构为具备层次感与空间景深的沉浸式「渐变冷灰/暗灰 (`bg-gradient-to-b from-[#181d28] via-[#121620] to-[#0c0f16]`) + 数字蓝图网格微纹理 (`bg-digital-grid`) + 顶部深紫/赛博青环境光晕」，所有卡片、容器、输入框与消息气泡全面收敛至高质感微反光与发丝描边体系。

## 3. 几何与色彩规范遵循 (Design Directives Compliance)

- **几何规范 (AGENTS.md §7)**:
  - 交互按钮：统一采用微圆角矩形 `rounded-md` (6px)，彻底杜绝椭圆形/胶囊形 `rounded-full`；
  - 容器与卡片：采用建筑微圆角 `rounded-lg` (8px) 或 `rounded-xl` (12px)；
  - 零 Unicode 表情符：全站严禁 emoji，使用标准的 Lucide 图标与状态徽章 `[LIVE · MONAD TESTNET]` / `[LOCKED]` / `[SUCCESS]`。
- **色彩规范 (AGENTS.md §7)**:
  - 零黄色/琥珀色；
  - 主色阶：深邃渐变灰 (`#242c3d` -> `#161c28` -> `#0c0f16`)；
  - 强调色：Monad 经典深紫 (`#836ef9`)、赛博青 (`#00f2fe`)、翡翠绿 (`#10b981`)。
