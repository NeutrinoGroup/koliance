# 077 · 补齐官网合规条款文档与公开定价路由（GAP-81）

## 1. 变更背景与治理动机

依据外部标准评测口径对拍（官网可用性与性能、定价透明度、文档与支持、条款与合规、开放与机器可读性，总分 100 分），Koliance 原站处于「底层技术设施与并行 EVM 结算能力极强、但商业包装、公开法务条款与专属在线文档站严重缺位」状态，初评仅 58 分：

1. **定价透明度（-4分）**：套餐信息深埋于 `/console` 内部标签页，无独立公开的一级路由 `/pricing`。
2. **文档与支持（-10分）**：线上 Footer 的 `Docs` 外链直接指向 Monad 公链文档，缺乏本项目专属的 Web 开发文档中心 `/docs`。
3. **条款与合规（-25分）**：全站无服务条款（`/terms`）、无隐私政策（`/privacy`）、无退款与安全保障规则（`/refund`）。
4. **开放与开源规范（-3分）**：虽然 `README.md` 声明了 MIT 协议，但仓库根目录物理缺失 `LICENSE` 文本文件，`package.json` 未标注协议类型。

本轮迭代针对上述 42 分缺口进行全量闭环修复，将系统评估指标提升至 98+ 分。

---

## 2. 变更内容与架构设计

### 2.1 补全物理 LICENSE 与开源授权
- 在仓库根目录创建标准 `LICENSE` 文件（MIT License，声明 Copyright (c) 2026 Koliance Contributors & Neutrino Group）。
- 在根目录 `package.json` 中配置 `"license": "MIT"`。

### 2.2 独立化 Pricing 路由（`/pricing`）
- 新建 `src/app/pricing/page.tsx`：
  - 严格遵循现代几何规范（`rounded-md` 交互按钮，`rounded-lg` 卡片，无 pill/capsule 椭圆，无黄褐色系）；
  - 明确标出三大阶梯套餐：
    - **Starter Pack**: `$0.00` / 3 次试用配额（每账户 300 次 API 免密调用，支持 EIP-712 Session Key）；
    - **Growth Pro**: `$19.90` / 10,000 次调用（300 RPM 并发，KOL 支付立享 15% 折扣，99.9% SLA）；
    - **Enterprise Scale**: `$149.00` / 100,000 次调用（1,200 RPM 专属队列，99.98% 高可用，企业级发票）；
  - 包含完整的特性对比表与常见问题（FAQ）。

### 2.3 部署专属开发者在线文档站（`/docs`）
- 新建 `src/app/docs/page.tsx`：
  - 涵盖六大模块：
    1. Quickstart & Sandbox：API Key 申请与 Curl 调用范例；
    2. Protocol Architecture：Monad 10,000 TPS 并行 EVM 吞吐与零延迟 Attestation；
    3. EIP-712 Session Keys：会话密钥委托规范、单笔与日度限额风控及熔断机制；
    4. Developer API Reference：Market 行情、配额鉴权与结算端点；
    5. Smart Contracts & Addresses：Monad Testnet (10143) 上真实部署的 Core Registry、SessionKeyRegistry、PositionManager 地址与浏览器直达链接；
    6. Error Handling (ADR-006)：标准闭集状态码定义。

### 2.4 补齐法务合规三件套
- `src/app/terms/page.tsx`（服务条款 Terms of Service）：明确去中心化非托管原则、链上交易不可逆性、EIP-712 授权责任边界、API 调用规范与免责声明。
- `src/app/privacy/page.tsx`（隐私政策 Privacy Policy）：严格确立「零明文私钥存储原则」、第三方 OAuth (GitHub/Google/Steam) 脱敏与去中心化映射原则、Cookie 与本地存储规范、GDPR/CCPA 用户权利。
- `src/app/refund/page.tsx`（退款政策与安全白皮书 Refund Policy & Security）：明确 14 天未消耗额度退款机制、免费试用零财务风险、浮点整数化数学严密性（GAP-06/14）以及 48 小时响应的负责任漏洞披露协议（Safe Harbor）。

### 2.5 统一全局页脚组件与机器可读性更新
- 新增 `src/components/GlobalFooter.tsx`，集中挂载全站产品、资源、合规条款与 Contact 直联通道，并在 `page.tsx`、`console/page.tsx`、`perp/page.tsx`、`token/page.tsx`、`market/page.tsx` 中全量统一采用。
- 更新 `src/app/sitemap.ts`：将 `/pricing`、`/docs`、`/terms`、`/privacy`、`/refund` 等路由全部纳入。
- 更新 `public/llms.txt`：为大模型抓取提供完整的结构化索引、套餐报价、退款规则与合约地址。
- 更新 `src/app/layout.tsx`：Schema.org JSON-LD 增加三大套餐的 `Offer` 结构化对象以及官方开源仓库 `sameAs` 标识。
