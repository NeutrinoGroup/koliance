  2. 程序死循环：一分钟发起 1,000 笔交易，手续费把钱包掏空；
  3. 女巫小号横行：链上智能合约根本分不清谁是正经 AI，谁是垃圾脚本。

### [卡片 3：解决方案 —— Koliance 三件套]
* **护栏 1：EIP-712 委托会话密钥**
  * 钱包主人签个名，限定 Agent 单笔最多花 $50，每天最多花 $200；
  * 超过限额合约直接拦截，异常时一键紧急熔断。
* **护栏 2：Agent Card 动态神经身份卡**
  * 0~1000 分链上信用评级；
  * 密码学绑定 GitHub 提交与开发活跃度，不泄露任何明文密码。
* **护栏 3：Monad 10,000 TPS 并行 EVM**
  * 1 秒确定性确认，单笔 Gas 费不到 0.1 分钱；
  * 支持几千个 Agent 同时微支付不卡顿。
